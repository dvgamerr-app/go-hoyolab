Why go-hoyolab

No login setup

Reuses your HoYoLAB session from Firefox. No passwords and no tokens to copy.

One small binary

A single hoyolab executable for Windows, macOS, Linux and FreeBSD. No runtime or Docker.

Every game, every account

All enabled games are checked in together, for each browser profile you have.

Know what you got

A Discord or LINE message lists today's reward for each game.

Updates itself

Picks up new releases from GitHub automatically.

Quick start

  1. Sign in to hoyolab.com in Firefox (or LibreWolf, Waterfox, Zen, Floorp).
  2. Download the archive for your OS from the latest release and unpack it.
  3. Run it. On the first run it writes a hoyolab.yaml next to the binary.
./hoyolab          # Windows: hoyolab.exe
./hoyolab --list   # show the browser profiles it found

Chrome, Edge and Brave are no longer supported. Their cookies use App-Bound Encryption (v20) and cannot be read from outside the browser. If your hoyolab.yaml has profile[].browser: chrome, edge or brave, change it to firefox.

Configuration

notify:
  discord-webhook: "https://discord.com/api/webhooks/..."
  line-notify: ""
  mini: true
profile:
  - browser: firefox
    name: []        # empty = every Firefox profile
games:              # remove the games you do not play
  - GSI
  - HSR
  - ZZZ

Notifications

Discord — create a webhook in Channel settings → Integrations and paste the URL into notify.discord-webhook.

LINE Notify — paste a token from notify-bot.line.me into notify.line-notify. LINE has retired this service, so prefer Discord.

Run it every day

Windows — Task Scheduler → Create Basic Task → Daily → Start a program → hoyolab.exe.

macOS / Linux — add a cron job:

0 5 * * * /path/to/hoyolab
